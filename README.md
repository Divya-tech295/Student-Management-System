# Student Management System

## About the Project

This is a beginner-level Student Management System
developed using the C programming language.

## Features

- Add Student
- Display Students
- Search Student
- Update Student
- Delete Student
- Duplicate Roll Number Checking
- Marks Validation (0-100)
- Exit

## Technologies Used

- C Programming Language
- GCC Compiler
- Visual Studio Code

## Concepts Used

- Variables
- Arrays
- Structures
- Loops
- If-Else
- Switch Case
- Input Validation

## How to Run

1. Compile the program using GCC.
2. Run the generated program.
3. Select an option from the menu.
